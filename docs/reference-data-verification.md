## ประเด็นค้างสำหรับ Phase 4 — ยังไม่ถือว่าตรวจยืนยัน

| กลุ่ม | สิ่งที่ต้องตรวจเพิ่มก่อนยกระดับฉาก |
|---|---|
| Green hydrogen | 250,000 ตัน/ปีต้องระบุช่วงข้อมูล; 900,000 ตันยังไม่ทราบว่าเป็น annual capacity หรือปริมาณอื่น |
| Equipment | นิยามตัวหารและขอบเขต localization 90%+; ข้อเปรียบเทียบมาตรฐานสากล |
| Stations | 557 completed / 177 planned / 650+ forecast; ห้ามบวกเป็น 734 operating; ต้องหา GGII เมษายน 2026 ฉบับจริง |
| Logistics costs | 30–40% ของราคาขายปลีกต้องตรวจพื้นที่ ปี และวิธีคำนวณ |
| Vehicles | 40,000 คัน / ใกล้ 3,600 คันต่อเดือน ปลายปี 2025; ไม่มีตัวเลขเดือนต้นปี 2026 ที่ยืนยัน |
| Fleet shares | 95% ของตลาด / 65% ของรถเชิงพาณิชย์; ข้อความ 85% ในเนื้อหาเดิมมีตัวหารต่างกัน ห้ามรวม |
| Storage and power | ตรวจทิศทางพลังงานและประเภทโครงการ; ข้อความ co-firing ต้องแยก hydrogen กับ ammonia อย่างถูกต้อง |
| Truck performance | 3–5 นาที, 600–1,000 km, −30°C ต้องระบุรุ่นและเงื่อนไข ไม่ขยายเป็นทุกคัน |
| Heavy logistics | 10,000 ตันสำหรับ convoy ต้องมีนิยาม ไม่ใช่ payload ต่อรถ |
| Passenger train | แยกต้นแบบปี 2022 ออกจากผลทดสอบระยะทางรุ่นหลัง; 15 นาทีต้องยืนยัน |
| Foshan tram | ใช้ถ้อยคำเชิงประวัติศาสตร์ปี 2019; ยังไม่ได้ตรวจบริการปัจจุบัน |
| Tourism trams | ชื่อ Qingchun Hao / Qingsong Hao ตาม prompt ใหม่ต่างจาก transliteration เดิม; เก็บเดิมไว้จนตรวจชื่อทางการและวันบริการ |
| Locomotives | เงื่อนไข 2,400 kW / 10,000 ตัน / 12+ ชม. และปี; 700/1,400 kW ไม่สร้างตัวเลขลด CO₂ ต่อรุ่น |
| Regional rail | เมืองทั้งเก้าไม่จำเป็นต้องมีบริการรถไฟแบบเดียวกัน ต้องตรวจประเภทและสถานะรายโครงการ |
| Challenges | 300,000 RMB / 1.5–4 เท่า / 35–70 MPa / 44.5 RMB/kg ต้องระบุฐานเปรียบเทียบ วัน และพื้นที่ |
