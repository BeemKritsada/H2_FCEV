# การตรวจสอบเนื้อหาและบันทึกภายใน (Content verification)

เอกสารภายในสำหรับทีมพัฒนาและเจ้าของเนื้อหา **ไม่แสดงในงานนำเสนอ** รวบรวมหมายเหตุการตรวจสอบ เลขสไลด์ต้นทาง และข้อมูลที่ยังไม่ยืนยัน ซึ่งถูกนำออกจากหน้าจอในการปรับถ้อยคำครั้งใหญ่ (Global presentation polish) วันที่ 2026-10-15

## หลักการที่ใช้

- รูปแบบป้ายที่มาบนหน้าจอ: `ที่มา: [แหล่ง] · ข้อมูลปี [ปี]` / `Source: [Source] · Data year: [Year]` แสดงปีเฉพาะเมื่อทราบจริง
- แหล่งที่ระบุชื่อบนหน้าจอมีเพียง NEA (ฉาก 2–3, ข้อมูลปี 2024 ตามรายงาน NEA ปี 2025) และ GGII (เฉพาะจำนวนสถานี 557 / 177 / >650 ซึ่งเอกสารต้นทางสไลด์ 19 อ้างถึง ข้อมูลเดือนเมษายน 2026) นอกนั้นใช้ "เอกสารประกอบการบรรยาย / Briefing material" คือไฟล์ `1 FCEV Logistics for China Present EEP.pptx`
- ปี 2026 คือปีอ้างอิงของการนำเสนอ ไม่ใช่ปีของข้อมูลทุกตัว ตัวเลขผลิตไฮโดรเจน 36.5 ล้านตันและโครงสร้างการผลิตแสดงเป็นข้อมูลปี 2024
- เมื่อไม่ทราบปีของข้อมูลและมีผลต่อการตีความตัวเลข หน้าจอเขียนว่า "ไม่ระบุปีของข้อมูล" แทนการเงียบ
- ไม่เปลี่ยนตัวเลข ช่วงค่า หน่วย ชื่อสถานที่ ปี หรือข้อกำหนดทางเทคนิค และไม่แก้ข้อมูลผู้บรรยายในหน้าสุดท้าย
- ข้อควรระวังทางวิทยาศาสตร์คงไว้ทั้งหมด (ท่อไอเสีย ≠ วงจรชีวิต, ระยะทาง/เวลาเติมขึ้นกับรุ่นและสภาพใช้งาน, เส้นบนแผนที่ไม่ใช่เส้นทางจริง, ค่าคาดการณ์ไม่ใช่ผลที่เกิดขึ้น, ระดับราคาเป้าหมายไม่ใช่จุดคุ้มทุน)

ถ้อยคำต่อไปนี้ถูกตรึงไว้แบบตรงตัวในสคริปต์ทดสอบ จึงยังไม่เปลี่ยนจนกว่าเจ้าของงานอนุมัติให้ปรับการทดสอบ

  - เสนอ TH: "ระบุในเอกสารประกอบการบรรยาย · ไม่มีข้อมูลสถานะโครงการล่าสุด" / "พื้นที่ทดสอบ/นำร่องตามเอกสารประกอบการบรรยาย · ไม่ระบุจุดดำเนินงาน"
- ฉาก 27 `batchEight.purchase.support` และ `refueling.support` (EN) — ยังมี "in the supplied reference" (`scripts/check-batch-eight.mjs`)
  - เสนอ: "…ICE or BEV alternatives, as reported." / "Most stations described in the briefing material use 35 MPa…"
