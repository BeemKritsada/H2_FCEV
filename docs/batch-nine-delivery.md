# Batch 9 — ฉาก 28–29

เพิ่มฉากข้อได้เปรียบและอุปสรรคของอุตสาหกรรมไฮโดรเจนต่อจากฉาก 27 Cold-chain โดยรักษาฉากเดิมทุกฉากไว้ตามลำดับเดิม จำนวนรวมจาก 31 เป็น 33 ฉาก: Regions ไปอยู่ 30, Advantages เดิมไปอยู่ 31, Challenges เดิมไปอยู่ 32 และ Closing ไปอยู่ 33 ไม่เปลี่ยน baseline หรือข้อมูลต้นฉบับ

## ไฟล์และโครงสร้าง

- `src/components/presentation/batch9/IndustryScenes.tsx`: ฉากใหม่สองแบบ มีภาพ/แผนภาพเฉพาะหัวข้อทั้งหมด 10 แบบ ใช้ wrapper และตัวควบคุม GSAP ร่วมกัน
- `src/styles/batch-nine-scenes.css`: รูปแบบเฉพาะฉากใหม่ ฉาก 28 ใช้แถบเลือกด้านล่าง ฉาก 29 ใช้แถบด้านซ้าย เดสก์ท็อปจัดเต็มหน้าจอ มือถือเรียงแนวตั้งและเลื่อนได้
- `src/content/en/batch-nine.json`, `src/content/th/batch-nine.json`: หัวข้อ ข้อความหลัก คำอธิบาย ข้อจำกัด alt text ป้ายแผนภาพและเครดิตทั้งหมดผ่าน i18next
- `src/i18n/index.ts`, `src/scenes/scene-config.ts`, `src/components/presentation/SceneContainer.tsx`: ลงทะเบียนภาษาและฉากใหม่
- `src/components/presentation/batch5/assets.ts`: prefetch ภาพจากโฟลเดอร์ถาวรเดิม
- `scripts/check-batch-nine-browser.mjs`, `package.json`: เพิ่มคำสั่ง `batch-nine:browser`
- ปรับเฉพาะจำนวนฉาก/รายชื่อฉากที่เพิ่มและการตรวจฉากถัดไปในสคริปต์ทดสอบ batch-two, batch-three, batch-four, batch-five, batch-five-browser และ cold-chain-browser ให้ตรงกับลำดับใหม่

## การโต้ตอบและแอนิเมชัน

แต่ละฉากเริ่มหัวข้อ 01 และแสดงปุ่มครบทั้ง 5 หัวข้อ ไม่เลื่อนหัวข้ออัตโนมัติ ปุ่มใช้ Tab และ Space/Enter ได้ มี focus ring, aria-pressed และเครื่องหมายถูกแสดงสถานะ นอกเหนือจากสี

ปรับตามคำขอล่าสุด: หน้า 27 และ 28 ใช้คลาส `performance-highlights` ร่วมกับหน้า 16 เป็นปุ่มขนาดตามข้อความ มีไอคอน ขอบบาง และสถานะเลือกสีน้ำเงิน ตัดเลขลำดับ/เครื่องหมายถูกบนปุ่มของหน้า 28 และย้ายแถบปุ่มมาอยู่ใต้ภาพ เหนือคำอธิบาย ตัวปุ่มไม่ remount เมื่อเลือกหัวข้อเพื่อรักษา keyboard focus หน้า 29 คงรูปแบบรายการเดิม การตรวจ browser เดิมผ่าน 32 กรณี Cold-chain และ 80 กรณี Batch 9 หลังปรับนี้ รวม TypeScript, lint และ build

เมื่อเปลี่ยนหัวข้อ ภาพเปลี่ยนด้วย GSAP ระยะ 0.65 วินาที ข้อความปรากฏตามมา 0.55 วินาที และส่วนย่อยในแผนภาพเรียงลำดับอย่างนุ่มนวล วงจรโครงสร้างพื้นฐานเรียงตามเข็มนาฬิกา เส้นการไหลและระดับการกักเก็บใช้ GSAP แบบเบา ไม่หมุนภาพรถ ไม่มีแฟลชหรือการเขย่า

แต่ละหัวข้อมี GSAP context ของตนเองและ revert เมื่อเปลี่ยนหัวข้อหรือออกจากฉาก การกดเร็วหยุดงานเก่าแล้วใช้หัวข้อสุดท้าย ปุ่มหยุดการเคลื่อนไหวกลางควบคุมทั้ง entrance และ ambient เมื่อหยุดแล้วเปลี่ยนหัวข้อจะแสดงเนื้อหาครบ รองรับ prefers-reduced-motion โดยไม่สร้างแอนิเมชัน

การสลับ TH/EN ไม่ remount หัวข้อ จึงคงตัวเลือกและไม่เริ่ม entrance ใหม่ ไม่มีสถิติเชิงปริมาณใหม่ในสองฉาก จึงไม่เพิ่ม count-up ให้เลขหัวข้อ ปี 2026 หรือสูตรเคมี ระบบ count-up กลางของฉากเดิมยังคงเดิม

## ภาพและส่วนที่ยังขาด

รายละเอียดเครดิตและไฟล์อยู่ใน `docs/batch-nine-assets.json` ใช้ภาพเดิม 6 ไฟล์จาก `public/assets/images/logistics/` และ `public/assets/images/challenges/` ไม่มีการใช้ `dist` เป็นต้นฉบับ ไม่มีการสร้างภาพใหม่หรือเพิ่มไลบรารี 3D

ภาพสถานีเป็นภาพจริงจากฟินแลนด์ ระบุสถานที่และเครดิต CC BY 4.0 บนภาพ ส่วนภาพรถ เหมือง โรงเหล็ก และท่าเรือเป็นภาพแนวคิดเดิม พร้อมคำกำกับ ไม่ใช่หลักฐานโครงการในจีน

ยังไม่มีภาพเฉพาะของรถในอากาศหนาว ศูนย์บริการเซลล์เชื้อเพลิง โรงเคมี และเรือ รวมถึงภาพ stack จริงและสถานีจีนที่มีสิทธิ์ใช้งานชัดเจน ใช้แผนภาพระบบหรือภาพบริบทที่มีพร้อมคำกำกับในส่วนเหล่านี้ รายการภาพเสริมระบุสัดส่วน รูปแบบ ความโปร่งใส และเส้นทางเสนอไว้ใน manifest ไม่อ้างว่าภาพเหล่านี้ถูกจัดหาแล้ว

## ขอบเขตข้อมูล

คำอธิบายหลัก 10 หัวข้อคงตามข้อกำหนด Batch 9 ที่ได้รับ แยกการปล่อยจากท่อไอเสียออกจากการปล่อยตลอดวงจรชีวิต ไม่อ้างว่าไฮโดรเจนทุกแหล่งปลอดคาร์บอน ไม่ระบุเวลาการเติมแบบครอบคลุมรถทุกแบบ ไม่อ้างว่าแบตเตอรี่เก็บพลังงานระยะยาวไม่ได้ และไม่อ้างว่าไฮโดรเจนเหมาะกว่าการใช้ไฟฟ้าโดยตรงเสมอ

ข้อความตลาดต้นปี 2026 อ้างเฉพาะเอกสารที่ผู้ใช้ให้ ไม่ได้ตรวจยืนยันกับฐานข้อมูลตลาดภายนอก และไม่อ้างเป็นผลทั้งปีหรือประมาณการ ไม่มีการเพิ่มยอดขาย เปอร์เซ็นต์ สัดส่วนไฮโดรเจนสีเขียว ต้นทุน ผลกำไร หรือจำนวนศูนย์บริการ ข้อความเรื่องต้นทุน เครือข่ายบริการและสัดส่วนการผลิตเป็นมุมมองเชิงคุณภาพจากเอกสาร ไม่ใช่ข้อมูลตลาดล่าสุดที่ตรวจยืนยันใหม่

## การตรวจสอบ

สคริปต์ browser ตรวจ 4 ขนาดจอ (1920×1080, 1440×900, 1366×768, 390×844) × 2 ภาษา × 10 หัวข้อ รวม 80 กรณี ตรวจข้อความที่กำหนด ภาพ โหลดครบ การล้น/ตัดข้อความ ระยะภาพ การนำทาง 27→28→29→30 และย้อนกลับ จำนวนฉาก 33, keyboard, reduced motion, pause/resume, สลับภาษา, rapid clicks และ GSAP cleanup พร้อมเก็บภาพและรายงานไว้ใน `tmp/batch-nine/qa/`

ผลตรวจสุดท้าย:

- `npm.cmd run typecheck`, `npm.cmd run lint`, `npm.cmd run build`: ผ่าน
- ตรวจ browser ของ Batch 9 บน production preview: ผ่าน 80 กรณี ไม่มี console/page error ภาพหรือข้อความหลุดกรอบตามเงื่อนไขตรวจ
- `cold-chain:browser`: ผ่าน 32 กรณี ยืนยันภาพทั้งสองคัน การนำทาง 26–28 และตัวเลขเรียงลำดับโดยไม่เล่นใหม่เมื่อสลับภาษา/ย้อนกลับ
- `batch-eight:browser`: ผ่าน 24 กรณีของฉาก Challenges ที่เลื่อนไปเป็นฉาก 32
- `batch-five:browser`: ผ่าน 48 กรณีของ Batch 5/6 และ 40 กรณีฉากก่อนหน้า รวมการเริ่ม session ใหม่ที่ฉากสุดท้าย 33 และ pause/resume
- `content:check`, `reference:check`, `reference:render`, `batch-one:check`, `batch-two:check`, `batch-three:check`, `batch-four:check`, `batch-five:check`, `batch-eight:check`: ผ่าน รวม render ทั้ง 33 ฉากใน TH/EN และการตรวจ baseline ของฉากเดิม
- ตรวจเทียบ attachment โดยตรง: label และคำอธิบายทั้ง 10 หัวข้อใน TH/EN ตรงตามข้อกำหนดทุกข้อความ รวมทั้ง translation keys และ numeric tokens ตรงกันระหว่างภาษา
- `git diff --check`: ผ่าน ไม่มี whitespace error (Git แจ้งการแปลง LF/CRLF ใน working copy ตามการตั้งค่าเดิม)

มีคำเตือนที่ไม่ทำให้ build ล้มเหลว: bundle หลักประมาณ 602 kB และ React Three Fiber ประมาณ 909 kB ก่อน gzip เกินเกณฑ์เตือน 500 kB; SSR ของฉาก 3D เดิมยังแจ้ง `THREE_CJS_DEPRECATED` ไม่ได้เพิ่ม dependency ใหม่ใน Batch 9

ตรวจภาพจริงหลังปรับกรอบรถให้เห็นครบ เครดิตไม่ถูกตัดบนจอแล็ปท็อป และย้ายป้าย CO₂ ไปอยู่กับกระบวนการผลิตต้นน้ำ เปิด development preview ที่ `http://127.0.0.1:5183/` และใช้ production preview ที่พอร์ต 5184 สำหรับทดสอบ ไม่มีการ deploy หรือแก้ไข production
