## ฉาก 09 — จำนวนรถที่ใช้งานในจีน

- ภาพรถบรรทุกขนาดใหญ่ทางขวา ตัวเลขหลักประมาณ 40,000 คันทางซ้าย ระบุว่าเป็นจำนวนสะสม ณ สิ้นปี 2025
- ตัวเลขรองเกือบ 3,600 คัน/เดือน ระบุช่วงปลายปี 2025 ไม่ทำให้ดูเป็นยอดขายสะสมหรือค่าเฉลี่ยรายปี
- แสดง “ข้อมูลล่าสุดปี 2026” เป็นบริบทอ้างอิง แยกจากปีของตัวเลขอย่างชัดเจน
- ระบุคำกล่าวว่าอันดับหนึ่งของโลกว่ามาจากข้อมูลต้นฉบับ ไม่อ้างว่าได้ตรวจยืนยันใหม่
- ลำดับเข้า: ภาพรถเปิดตัว → count-up 40,000 → เน้นตัวเลขรายเดือน ตัวเลขสุดท้ายพร้อมในเวลาประมาณสองวินาที
- เคลื่อนมุมภาพรถทั้งภาพอย่างช้า ๆ มีแสงและเส้นพลังงานแยกชั้น ไม่หมุนล้อหรือสร้างการเคลื่อนกลไกจากภาพแบน

## ฉาก 10 — ตลาดเปลี่ยนผ่าน

- ใช้สองช่วงใหญ่: ปลายปี 2025 แรงส่งจากนโยบาย และต้นปี 2026 ยอดผลิต/ยอดขายลดลงอย่างมีนัยสำคัญ
- สรุปด้านล่างว่าตลาดเข้าสู่ช่วงปรับตัวเชิงพาณิชย์ที่มีเหตุผลมากขึ้น
- ใช้เส้นเล่าเรื่องจากซ้ายไปขวาและหมุดขนาดคงที่ วาดเส้นด้วย GSAP ตามลำดับ พร้อมสัญญาณเคลื่อนช้าและวง pulse หลังเข้าเสร็จ
- มีคำอธิบายว่าเป็นช่วงตลาดเชิงคุณภาพ ไม่มีสเกลกราฟที่วัดยอดขาย จุดข้อมูลรายเดือน หรือเปอร์เซ็นต์การลดลงที่แต่งขึ้น ไม่ใช้รถบรรทุกเป็นภาพหลักซ้ำ

## ฉาก 11 — โครงสร้างตลาด

- กลุ่มรถพาณิชย์ 95%+ เป็นองค์ประกอบหลัก พร้อมข้อความ “มากกว่า 95% ของตลาดทั้งหมด”
- กลุ่มรถเก๋ง <5% อยู่ด้านข้าง พร้อมข้อความ “น้อยกว่า 5% ของตลาดทั้งหมด”
- วาง 65%+ รถบรรทุกหนักไว้ในแผงย่อยที่เยื้องอยู่ใต้ภาพหลักภายในกลุ่มรถพาณิชย์ พร้อมคำอธิบายชัดเจนว่าใช้รถพาณิชย์เป็นฐาน ไม่ใช่รถไฮโดรเจนทั้งหมด
- ไม่มี pie chart ที่รวมเปอร์เซ็นต์ต่างฐานเข้าด้วยกัน ภาพรถมีไว้แสดงลำดับความสำคัญ ไม่เข้ารหัสสัดส่วนตลาดแบบแม่นยำ
- แสดงรถทั้งสามภาพพร้อมกันใน carousel: รถบรรทุกอยู่กลางเป็นค่าเริ่มต้น และรถโดยสาร/รถเก๋งอยู่ตำแหน่งรอง กดภาพด้านข้างเพื่อเลื่อนมาเป็นภาพหลัก
- คงภาพรวม 95%+ รถพาณิชย์, <5% รถยนต์นั่ง และ 65%+ รถบรรทุกหนักภายในกลุ่มพาณิชย์ไว้ขณะเปลี่ยนภาพ รายละเอียดหลักเปลี่ยนตามรถที่เลือก
- ใช้ภาพตัดพื้นหลัง PNG ที่ผู้ใช้เตรียมไว้ ไม่หมุนหรือบิดภาพ และใช้ข้อความ TH/EN ใน DOM ไม่ฝังในภาพ

## Assets และสิ่งที่ยังขาด

Scene 09 ยังคงใช้ `public/assets/images/hydrogen-truck.jpg` ผ่าน HeroTruck โดยไม่แก้ไข Scene 11 ใช้ภาพ `รถบรรทุกไฮโดรเจนสีขาวฟ้าล้ำสมัย.png`, `รถบัสไฮโดรเจนล้ำสมัยสีขาวมุก.png` และ `รถซีดานไฮโดรเจนหรูสีขาวประกายเงิน.png` คัดลอกจาก `dist/assets/images` ไปยัง `public/assets/images/vehicles/` โดยเก็บต้นฉบับใน `dist` ไว้

ภาพใหม่ทั้งสามเป็น PNG RGBA ขนาด 1672×941 และมีพื้นหลังโปร่งใส อัตราส่วนภาพเท่ากัน จึงใช้ `object-fit: contain` ได้โดยไม่ตัดขอบรถ ยังไม่มีภาพที่ระบุรุ่นจริงและตรวจสอบทางเทคนิคแล้ว

รายละเอียดอยู่ใน `public/assets/batch-three-manifest.json` ไม่มีการดาวน์โหลดภาพใหม่หรือเพิ่ม dependency

## แอนิเมชัน ภาษา และประสิทธิภาพ

ใช้ lifecycle ของ Batch 2 ผ่าน `useInfrastructureMotion` โดยไม่แก้ helper เดิม Scene 11 ใช้ GSAP เคลื่อนตำแหน่งตามแกน X และปรับ scale/opacity ใช้ easing `power3.inOut` ระยะเวลา 0.78 วินาที และยกเลิก tween เดิมก่อนเริ่ม tween ใหม่เพื่อรองรับการกดซ้ำ ภาพทุกภาพยังอยู่ใน DOM และการเปลี่ยนภาษาไม่รีเซ็ตรถที่เลือก เมื่อเปิด reduced motion การเลือกจะเปลี่ยนตำแหน่งทันที

GSAP คืนค่าเมื่อออกจากฉาก และสร้าง entrance ใหม่เมื่อกลับมา ไม่มี auto-advance ไม่มีการอัปเดต React state ทุกเฟรม ตัวนับเขียนลง DOM โดยตรงและมีค่าฉบับเต็มสำหรับ screen reader เมื่อ pause หรือหลุด viewport จะจบ entrance ไปที่ค่าจริง เพื่อไม่ค้างตัวเลขนับระหว่างทาง เมื่อเริ่มด้วย pause ตัวเลขสุดท้ายถูกแสดงก่อน paint; reduced motion แสดงสถานะสุดท้ายโดยไม่มีการเคลื่อนไหว

ใช้ i18next namespace เดิม โดยเพิ่มไฟล์คำแปล TH/EN ของ Batch 3 การเปลี่ยนภาษาไม่สร้าง active scene ใหม่และไม่เริ่ม timeline ใหม่ ข้อความสำคัญทุกส่วนเป็น DOM ที่แก้ได้ ไม่ฝังในภาพ

CSS แยกภายใต้ `.batch-three-scene` และใช้ typography/color tokens เดิม มี breakpoint สำหรับ desktop, viewport เตี้ย และ mobile ภาพโหลดจาก public path พร้อมกำหนดมิติภาพล่วงหน้าและ preload รถบรรทุกที่เลือกเป็นค่าเริ่มต้น

## ข้อมูลที่ยังรอตรวจแหล่งอ้างอิง

- จำนวนสะสมประมาณ 40,000 คันและยอดขายเกือบ 3,600 คัน/เดือน ใช้ตามสไลด์ 5 ยังไม่มีการยืนยันกับชุดข้อมูลทางการรายเดือนในรอบนี้
- คำกล่าวว่าอันดับหนึ่งของโลก และความสัมพันธ์กับแรงกระตุ้นนโยบาย คงการอ้างถึงต้นฉบับ ไม่เพิ่มชื่อมาตรการหรือเหตุผลที่แหล่งข้อมูลไม่ได้ระบุ
- สไลด์ 5 ระบุรถบรรทุกหนักมากกว่า 65% ของรถพาณิชย์ ขณะที่สไลด์ 6 มีค่า 85% ในอีกบริบท ขอบเขต/ช่วงเวลา/ฐานของ 85% ยังต้องยืนยัน ไม่รวมสองค่านี้หรือแปลงเป็นเปอร์เซ็นต์ตลาดทั้งหมด ฉาก 11 ใช้ 65% ตามคำสั่ง Batch 3 โดยคง source sections เดิม
